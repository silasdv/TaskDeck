# Privacy

TaskDeck works locally and has no INTERNET permission, advertising, analytics or screen-content retrieval. Task titles/package names, running-process/PSS samples and operation reports are used transiently for the interface and are not saved as usage history.

Preferences store explicit choices: controller mappings/page-navigation bindings/label profile, digital shortcut identifiers, theme/accent/view, setup completion, notification/closing behavior, protected package names, ordered Dock package names, dock size/style/side-swap/behavior and optional close vibration. Accessibility filters only opt-in shortcut key events and discards accessibility-content events. Shizuku is a separate app with its own permissions.

VIBRATE supports opt-in short close feedback. Legacy preferences may remain after upgrades.

Shizuku help, Ko-fi and GitHub buttons open an external browser. The browser and those services apply their own policies; TaskDeck does not send task lists, RAM samples or controller data to them.

Optional manual settings backups contain configuration, including favorite/protected package identifiers and controller bindings. They contain no task history, RAM reports, typed text or Android permission grants. Files are unencrypted JSON in the document provider selected by the user; that provider has its own policies. TaskDeck does not upload backups itself. Uninstalling clears app settings but does not delete independently saved backup files.

Uninstalling clears TaskDeck settings. Do not include private app titles, screenshots, account details or signing material in public bug reports.
