# Privacy

TaskDeck works locally and has no INTERNET permission, advertising, analytics or screen-content retrieval. Task titles/package names, running-process/PSS samples and operation reports are used transiently for the interface and are not saved as usage history.

Preferences store explicit choices: controller mappings/page-navigation bindings/label profile, digital shortcut identifiers, theme/accent/view, setup completion, notification/closing behavior, protected package names, unlocked launchers, ordered Quick Access package names and dock size/style/theme/behavior. Accessibility filters only opt-in shortcut key events and discards accessibility-content events. Shizuku is a separate app with its own permissions.

Ko-fi and GitHub buttons open an external browser. The browser and those services apply their own policies; TaskDeck does not send task lists, RAM samples or controller data to them.

Uninstalling clears TaskDeck settings. Do not include private app titles, screenshots, account details or signing material in public bug reports.
